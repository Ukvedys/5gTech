# 5G TECH paslaugos puslapio šablonas

Šis šablonas skirtas visoms šešioms 5G TECH paslaugoms. WordPress administracijoje žmogus neturėtų dėlioti maketo ar rinktis dizaino blokų. Jis užpildo vieną aiškią formą, o puslapis sugeneruojamas automatiškai.

## Ką administratorius pildo

1. **Paslaugos pavadinimas**
2. **Kategorijos žyma** – pavyzdžiui, „Telekomunikacijos“ arba „Energetika“
3. **Trumpas aprašymas** – iki 2–3 sakinių
4. **Pagrindinė nuotrauka**
5. **Atliekamų darbų sąrašas** – paprastos kartojamos eilutės
6. **Įrangos gamintojai** – pasirenkami iš bendro sąrašo
7. **DUK** – neprivalomi klausimo ir atsakymo laukai

## Kas įdedama automatiškai

- navigacija ir poraštė;
- bendri įmonės patirties rodikliai;
- penkių žingsnių darbo procesas;
- galutinis kontaktinis CTA;
- tinklelis, spalvos, tipografija ir adaptyvus dizainas.

## WordPress realizavimo principas

- Kurti turinio tipą **„Paslaugos“**.
- Naudoti vieną fiksuotą puslapio šabloną visoms paslaugoms.
- Administravimui pateikti paprastus laukus, ne laisvą puslapio konstruktorių.
- DUK sekciją slėpti automatiškai, jei neįrašytas nė vienas klausimas.
- Gamintojus pateikti kaip pasirinkimus iš bendro sąrašo, kad pavadinimai visur būtų vienodi.
- Bendrus rodiklius, proceso tekstą ir CTA redaguoti vienoje globalioje WordPress nustatymų vietoje.

## Panaudojimas

Tas pats šablonas dubliuojamas šioms paslaugoms:

- Mobiliojo ryšio tinklai
- Vidinio ryšio tinklai
- Fiksuoto ryšio tinklai
- Elektros darbai
- Apsaugos ir stebėjimo sistemos
- Saulės elektrinės
